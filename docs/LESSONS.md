# Μαθήματα από τα 7 sites → κανόνες για το TGW

Κάθε λάθος που έγινε στα CGW, MGW, WGW, KGW, HGW, GGW και στο Hub γίνεται εδώ κανόνας.
Το TGW χτίζεται έτσι ώστε κάθε κανόνας να **ελέγχεται αυτόματα** (QA gate) πριν από κάθε deploy.
Μετά, οι ίδιοι έλεγχοι τρέχουν και στα άλλα sites για να βρουν τι πρέπει να διορθωθεί.

Οι κωδικοί T01–T35 είναι οι εργασίες του πλάνου διορθώσεων.
